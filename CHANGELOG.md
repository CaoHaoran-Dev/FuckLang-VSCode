## [1.1.0] - 2026-11-15

### Added
- Auto-completion for user-defined function names (`bitch foo(...)`), function parameters, anonymous function parameters, and `orgy` loop variables
- Namespace member completion triggered by `.` (`str.` / `arr.` / `file.`)
- Built-in function completions now include signatures and Markdown documentation
- `FuckLang` Output channel records interpreter download progress and LSP startup status
- Run command adapts to the active shell (uses `&` on PowerShell, direct invocation on cmd/bash)
- Snippets for `str.*`, `arr.*`, and `file.*` methods

### Changed
- Completion scanner now skips comments and strings, so `// shit fake` no longer pollutes the suggestion list
- Syntax highlighting updated with the full built-in function list, namespace/member distinction, and `true`/`false` support
- `else damn` snippet fixed to insert immediately after the preceding `}`
- `language-configuration.json` gains `wordPattern`, `indentationRules`, and `onEnterRules`
- README updated with feature descriptions, interpreter cache paths, and known issues
- Removed redundant `activationEvents` entries now auto-generated by VS Code from `contributes`

### Fixed
- LSP startup failure no longer throws "Client is not running and can't be stopped" or "Pending response rejected"; the real cause is logged to the Output panel
- Corrected language server module path to prevent `startFailed`
- Missing `&` invocation operator on PowerShell causing `ParserError` when running files
- `LanguageClientOptions.outputChannel` type mismatch by switching to `LogOutputChannel`
